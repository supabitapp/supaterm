# Supaterm Skill

```bash
sp skills install
sp skills get core
sp skills get core --full
sp skills path core
sp skills get coding-agents
```

`sp skills install` asks the running Supaterm app to copy a stable discovery skill to `~/.agents/skills/supaterm`. Claude, Codex, Pi, and other agents that support the Agent Skills paths read the same copy. The detailed guides stay in the app bundle so their commands always match the running version. Every `sp skills` command needs a reachable app.
